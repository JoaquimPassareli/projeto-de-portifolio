# Portifolio e Calculadora de Abastecimento

Este repositório reúne dois projetos front-end desenvolvidos com HTML, CSS e JavaScript:

- Portfólio pessoal
- Calculadora de abastecimento

## Projetos

### 1) Portfólio
Pasta: `portifolio/`

Site pessoal com informações sobre:
- apresentação profissional
- experiência
- habilidades
- projetos
- contatos

No card do projeto de calculadora existe um botão que abre o segundo projeto.

### 2) Calculadora de Abastecimento
Pasta: `projeto calcular abastecimento/`

Aplicação para estimar o próximo abastecimento com dois modos de cálculo:
- por autonomia atual do veículo
- por valor e litros abastecidos

Funcionalidades principais:
- cálculo da previsão de próximo abastecimento
- conferência de valor total por litros x preço por litro
- histórico de cálculos salvo no navegador (`localStorage`)
- remoção de itens do histórico
- seção de contato/feedback

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (vanilla)

## Como executar localmente

Como são projetos estáticos, você pode executar de forma simples:

1. Clone o repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

2. Abra a pasta clonada no VS Code.
3. Abra `portifolio/index.html` no navegador.
4. Para acessar a calculadora diretamente, abra `projeto calcular abastecimento/index.html`.

Sugestão: use a extensão Live Server no VS Code para facilitar testes durante o desenvolvimento.
